# geo2model 使用说明

本手册介绍 `geo2model` 基于平面地质图的智能化三维地质建模系统的运行方式。

---

## 1. 运行环境与安装

项目基于 Python 3.14，使用开源工具链（OpenCV、scikit-image、GemPy 2026、PyVista、Gradio）。

```bash
cd geo3d_project

# 创建并激活虚拟环境
python3 -m venv .venv-gempy
source .venv-gempy/bin/activate   # Windows: .venv-gempy\Scripts\activate

# 安装依赖
pip install -r requirements-geo2model.txt
```

---

## 2. 方式一：Web 图形界面（推荐）

双击项目根目录的 **`启动界面.command`**（macOS），或在终端运行：

```bash
.venv-gempy/bin/python app/geo2model_app.py
```

浏览器会自动打开 `http://127.0.0.1:7860`，支持三个核心功能页签：
1. **快速演示**：快速浏览已生成的典型三维地质模型、交互式 3D 页面、剖面图与地表重建图；
2. **新地图全流程**：上传一张地质图图片（JPG/PNG），设置基础参数，点击提取后在交互表格中审核地层层序、确认断层与等高线高程，一键构建 3D 模型；
3. **模型工程查询**：在已建成的模型中任选坐标进行虚拟钻孔柱状图查询、任意两点地质剖面绘制以及任意标高水平切片提取。

---

## 3. 方式二：命令行脚本运行

### 3.1 一键运行标准合成案例

```bash
PY=.venv-gempy/bin/python

# 1. 生成 6 个合成基准场景（含地质图、剖面图与像素级真值）
$PY scripts/10_gen_synthetic_map.py

# 2. 运行标准案例端到端建模（含剖面深部约束）
$PY scripts/11_run_pipeline.py configs/synth_base_deep.json

# 3. 浏览器查看生成的可交互 3D 模型
open data/output/geo2model/synth_base_deep/model/model_3d.html  # macOS
```

### 3.2 批量测试与评估

| 脚本命令 | 功能说明 |
|---|---|
| `$PY scripts/12_evaluate_all.py` | 批量运行 6 个合成场景并汇总准确率、DEM 误差与体素一致率指标表 |
| `$PY scripts/13_robustness.py` | 运行 7 种扫描退化 × 4 档强度的全矩阵鲁棒性测试并生成曲线图 |
| `$PY scripts/11_run_pipeline.py configs/real_map1.json` | 运行真实教学地质图 1（湖区 + 14 单元褶皱带）全流程 |
| `$PY scripts/11_run_pipeline.py configs/real_map2.json` | 运行真实教学地质图 2（不整合覆盖 + 点线等高线 + 剖面线）全流程 |

## 4. 输出产物说明

每次运行的产物均输出至指定案例目录（如 `data/output/geo2model/<案例名>/`）：

| 产物文件 | 说明 |
|---|---|
| `model/model_3d.html` | **交互式 3D 网页**：在浏览器中自由 360° 旋转、缩放与视角切换 |
| `model/geomap_rebuilt.png` | **地表重建地质图**：由三维模型在地表截取重建的地质出露图 |
| `model/section_x_mid.png` / `section_y_mid.png` | 模型正交截面剖面图 |
| `apps/borehole_1.png` / `.csv` | 虚拟钻孔柱状图及分层深度/厚度 CSV 表 |
| `apps/section_1.png` | 任意两点剖面切片图（含地表地形与地层填色） |
| `apps/slice_1.png` | 任意地下高程水平平切图 |
| `eval/pipeline_report.json` | 端到端全流程运行耗时与指标报告 |
