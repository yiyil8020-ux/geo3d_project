# 使用说明

## 一、合成数据 + GemPy 三维建模（当前可跑通）

图像提取暂未稳定时，先用合成 CSV 验证建模端。

### 1. 安装建模环境（与图像处理 venv 分离）

```bash
cd geo3d_project
python3 -m venv .venv-gempy
.venv-gempy/bin/pip install -r requirements-modeling.txt

# 可选：导出 3D 截图
.venv-gempy/bin/pip install pyvista
```

### 2. 生成合成层位/产状数据（含褶皱 + 正断层）

```bash
.venv-gempy/bin/python scripts/01_make_synthetic_data.py
```

生成：

- `data/csv/synthetic/surface_points.csv`（地层界面 + `Main_Fault`）
- `data/csv/synthetic/orientations.csv`（翼部变化产状 + 断层产状）

场景要点：圆柱状褶皱、向东倾正断层（上盘下落）、建模时再叠加丘陵/断层谷地形。

### 3. 三维建模并出图

```bash
.venv-gempy/bin/python scripts/02_gempy_model.py
# 默认会导出可交互 HTML，并尝试用浏览器打开
# 若不想自动开浏览器：
.venv-gempy/bin/python scripts/02_gempy_model.py --no-browser
# 额外弹出桌面 3D 窗口（可实时旋转，关闭窗口后结束）：
.venv-gempy/bin/python scripts/02_gempy_model.py --interactive
```

输出目录：`data/output/synthetic/`

| 文件 | 含义 |
|------|------|
| **`model_3d.html`** | **可交互 3D（主结果）**：浏览器打开，拖拽旋转 / 滚轮缩放 |
| `model_3d.png` | 静态 3D 预览截图 |
| `input_data_2d.png` | 输入控制点/产状 |
| `section_y_mid.png` | Y 向中间剖面（X–Z） |
| `section_x_mid.png` | X 向中间剖面（Y–Z） |

打开交互 3D：

```bash
open data/output/synthetic/model_3d.html   # macOS
```


### 4. 输入数据契约（后续图像提取应对齐）

任意来源最终都产出同一对 CSV，再交给 `02_gempy_model.py`：

```text
surface_points.csv  →  X, Y, Z, formation
orientations.csv    →  X, Y, Z, azimuth, dip, polarity, formation
```

- 每层至少多个 surface points
- 每层至少 1 个 orientation
- `formation` 名称需与 `map_stack_to_surfaces` 中的层序一致
