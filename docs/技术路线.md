# 技术路线

`geo2model` 系统采用模块化、数据契约驱动的技术路线，将二维栅格地质图转换为三维隐式地质模型。

---

## 总体技术链路

```text
二维平面地质图 (JPG/PNG)
    │
    ├──► 阶段 1：图像智能矢量化 (segment / vectorize / terrain)
    │       └─ 提取地层分区、接触界线、断层候选、等高线 DEM
    │
    ├──► 阶段 2：数据库构建与空间配准 (geodatabase / constraints / sectionreg)
    │       └─ 交互审核表、分窗三点法产状估算、剖面深部约束像素比例映射配准
    │       └─ 输出标准 surface_points.csv + orientations.csv
    │
    ├──► 阶段 3：三维隐式建模与多源导出 (model3d - GemPy 2026)
    │       └─ 协同克里金标量场插值、断层切割、侵蚀不整合、DEM 地形挂接
    │       └─ 导出交互 HTML、OBJ、glTF、VTK 体素与层面网格
    │
    └──► 阶段 4：工程应用扩展与地学解释 (apps)
            └─ 虚拟钻孔柱状图查询、任意两点剖面提取、任意标高水平平切图
```

---

## 关键技术突破

1. **扫描退化复合预处理**：
   结合保边双边滤波与自适应非局部均值（NL-Means）去噪，辅以残差式两遍聚类光照校正，有效抵御扫描噪声与不均匀光照。
2. **CIELAB 空间过聚类与自适应合并**：
   在感知均匀的 CIELAB 色彩空间进行 $K=22$ 过聚类，依据 $\Delta E < 5.0$ 严选阈值进行层次合并，精确分离色调相近的地层单元。
3. **接触线分窗三点法产状解算**：
   沿接触线进行 12 点滑动窗口平面拟合，配合高差、展布与倾角三道质控关卡，在不依赖人工符号的前提下自适应估算褶皱两翼产状。
4. **剖面图深部约束像素比例映射配准**：
   构建横轴线性弧长映射与纵轴高程解算引擎，将地质剖面图中的深部采样点精确映射为三维世界坐标，大幅降低地下建模的多解性。
