# 技术路线

## 总体链路

```text
（A）地质图信息提取  ──┐
                       ├──► surface_points.csv + orientations.csv ──► GemPy ──► 三维模型
（B）合成/人工数据    ──┘
```

当前策略：**先用路径 B 跑通建模，再回头加强路径 A。**

## 路径 B：合成数据建模（已实现）

1. `01_make_synthetic_data.py`：按平面方程生成多层缓倾界面点 + 产状
2. `02_gempy_model.py`：ImporterHelper 读 CSV → map_stack → compute_model → 出图
3. 工具：GemPy 2026 + gempy_viewer（可选 pyvista）

## 路径 A：平面地质图信息提取（待加强）

纯颜色聚类对扫描质量要求高，且不适用于黑白图。文献结论见 `文献/阶段一/`：

- **彩色图**：图例驱动 + 超像素/区域匹配 + 人机交互 + 拓扑修复
- **黑白图**：线划提取 + 骨架追踪（与颜色聚类分轨）
- 最终输出必须落到与路径 B 相同的 CSV 契约

## 与三维建模的接口

GemPy 需要的是**位置 + 梯度 + 层序/拓扑**，不是图片轮廓本身：

| 数据 | 文件 | 作用 |
|------|------|------|
| 层位控制点 | surface_points.csv | 界面位置（层底） |
| 产状 | orientations.csv | 界面法向/倾角倾向 |
| 地层序列 | 代码中 map_stack_to_surfaces | 新老关系 |

后续从地质图提取时，只需填满上述字段（再加可选断层），不必改建模脚本主体。
